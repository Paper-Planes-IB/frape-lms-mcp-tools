## Доработка списка Wiki и ротация токена

`list_kb_articles` возвращает только `name`, `title`, `category`, `snippet`.
Фрагмент ограничен 300 символами. При поисковом запросе фрагмент выбирается рядом с совпадением.
Полный текст статьи доступен через `get_kb_article`; поиск LMS использует короткий фрагмент Wiki.

После выкладки проверены все 14 инструментов. JSON списка из 50 реальных статей — 29270 байт.
Чтение полного текста отдельной статьи сохранено. Прошли 18 локальных тестов, включая
регрессию на статье длиной свыше миллиона символов и списке из 200 статей.

MCP-токен перевыпущен. Проверка по HTTPS: старый токен — 401, новый initialize — 200.
